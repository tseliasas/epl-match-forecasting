# EPL Match Forecasting

Predicting Premier League match outcomes from recent team form and testing whether the model finds value against bookmaker odds (paper bets only).

Work in progress.

## Setup

```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

Data: football-data.co.uk, Premier League (E0), downloaded to `data/raw/` (not committed).
